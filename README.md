# Credit Card Fraud Risk Analysis Dashboard

## Project Overview
This project focuses on analyzing credit card transactions and identifying fraudulent activities using **Microsoft Power BI**. The dashboard provides insights into fraud patterns, transaction categories, risk levels, and geographical distribution to support better fraud monitoring and risk assessment.

## Objectives
- Analyze fraudulent and non-fraudulent transactions.
- Identify fraud patterns across different transaction categories.
- Understand fraud risk distribution.
- Analyze fraudulent transactions across states.
- Track monthly trends in fraudulent transactions.
- Monitor key fraud-related performance indicators.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Visualization
- Data Analysis

## Dashboard Features

- **Fraud Risk Analysis:** Overview of fraud-related metrics and risk distribution.
- **Transaction Category Analysis:** Analysis of transaction amounts across different fraud types and transaction categories.
- **Fraud Risk Distribution:** Visual representation of transaction amounts by fraud risk.
- **Geographical Analysis:** State-wise analysis of fraudulent transactions.
- **Monthly Trend Analysis:** Tracking fraudulent transactions over time.
- **Interactive Filters:** Filters for Fraud Type, State, and Merchant Name.

## Key Performance Indicators (KPIs)
- Fraud Rate
- Fraudulent Transactions
- Critical Risk Transactions
- Fraudulent Transaction Amount
- Top Fraud Type

## Conclusion
This dashboard provides an interactive overview of credit card fraud patterns and risk indicators. It helps explore transaction behavior, identify potential fraud trends, and understand the distribution of fraudulent activities across different dimensions.
